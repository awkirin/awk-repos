# Проверка аудита

## Исправлено

| Дефект | Исправление |
| --- | --- |
| `New-AnswerIso.ps1` не компилировался одинаково в Windows PowerShell 5.1 и PowerShell 7 | Устранён вызов `Marshal.QueryInterface` с несовместимыми между версиями модификаторами; добавлен регрессионный тест. |
| Архитектурный поток не содержал подготовку Sysprep | В поток добавлены Answer ISO и prepare Sysprep. |
| `verify.ps1` не проверял локаль и Sysprep answer file | Добавлены проверки `ru-RU` и `SysprepUnattend.xml`. |
| `Test-Path` нарушал соглашение проекта | Для известного пути используется `-LiteralPath`. |

## Отклонено

| Гипотеза | Причина |
| --- | --- |
| Объединить WinRM-команды в один скрипт | Команды выполняются на разных этапах; до первого WinRM-подключения гостевой скрипт ещё недоступен. |
| Объединить verify и smoke-проверки | Они проверяют разные состояния: до и после Sysprep. Пересечение является проверкой сохранения контракта. |
| Проверять в тестах порядок каждого provisioner-а, README-путь и SATA-порт | Текущая конфигурация согласована; тесты не должны повторять все детали реализации. |
| Проверять индекс редакции ISO до установки | ISO закреплён URL и SHA-256; дополнительная проверка потребует лишнего инструмента и продублирует гостевую проверку. |
| Удалять диагностические файлы из `build/` | `build/` предназначен для игнорируемых временных результатов и не входит в VCS. |
| Добавить `variables.pkr.hcl` или подпапки гостевых скриптов | Проект собирает один фиксированный box; новые уровни не устраняют существующую сложность. |
| Удалить защитный шаблон `*.box` из `.gitignore` | Он предотвращает добавление box вне `output/`. |

## Проверка

- `New-AnswerIso.ps1` выполнен в Windows PowerShell 5.1.
- `Test-Project.ps1` выполнен в Windows PowerShell 5.1.
- Полная сборка и smoke-тест требуются после изменения гостевой проверки.
